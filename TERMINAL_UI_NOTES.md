# Единый терминальный стиль админ-панели

## Статус
Пакет исходников, основан на marzban-hysteria2-fix-03.zip. Все три исправления
Hysteria сохранены. Backend, API, схема БД и обработчики сохранения не менялись.
Страница подписки для конечного пользователя (app/templates/subscription) не менялась.

Полная production-сборка и проверка всех маршрутов пока НЕ выполнены.
Не разворачивать этот архив как проверенный готовый frontend без сборки.

## Что изменено
- Новый общий слой src/theme/terminal.ts, подключённый после существующей
  Chakra-темы: моноширинный шрифт, контрастные подписи, тёмные поля, состояния
  фокуса/ошибок/disabled, меню, поповеры, формы, вкладки, аккордеоны и диалоги.
- Зелёный основной акцент сохранён. Деструктивные кнопки с colorScheme=red
  действительно красные, а не зелёные; предупреждения и ошибки различимы.
- XHTTP и WireGuard используют общий компонент Panel с терминальными заголовками.
- Убраны локальные светлые/серые фоны логов, сертификатов и часть независимых
  overlay-переопределений. Не затронуты обработчики действий.
- Добавлена именованная терминальная тема Monaco с тем же фоном и палитрой.
- Увеличены мобильные области нажатия; диалогам добавлены боковые поля.
- Учтено prefers-reduced-motion. Стиль уже оформленной основной страницы
  наследуется через существующую тему, а не заменяется новым дизайном.

## Проверено
- Парсером проверен синтаксис 62 TS/TSX файлов src.
- Слой темы и компонент Panel исполнены с настоящей библиотекой Chakra из
  существующего vendor-бандла архива, без переустановки пакетов.
- Визуально проверены стенд общих компонентов (1440px), реальный SettingsEditor
  из XHTTP (desktop и 390px), мобильное модальное окно на тестовых данных.
- На проверенных стендах нет горизонтального переполнения и ошибок JS.
- Проверены текстовые пары цвета/фона; яркость основных границ полей повышена.

## Не проверено
- Полная проверка TypeScript типов и npm run build.
- Все маршруты с реальными API-данными, все модальные окна/вкладки/ошибки,
  редактирование и сохранение, Monaco в составе приложения, графики и календарь.
- Исходники Sidebar в стенде не использовались: навигация стенда — тестовая оболочка.
  Превью модального окна — набор настоящих Chakra-компонентов, не весь UserDialog.
- Проверка reduced-motion и клавиатурной навигации во всех реальных экранах.

npm ci --offline завершился ENOTCACHED: отсутствует пакет @monaco-editor/react.
Сетевые зависимости установить в этом окружении не удалось. Каталог
app/dashboard/build в архиве оставлен неизменным: он НЕ содержит эту тему.
Готовый бандл в исходном архиве также старее предоставленных исходников.

## Сборка
В окружении с Node.js и доступом к npm, из корня распакованного проекта:

```bash
cd app/dashboard
npm install --no-audit --no-fund
VITE_BASE_API=/api/ npm run build -- --outDir build --assetsDir statics
cp build/index.html build/404.html
```

Команды соответствуют существующему CI проекта. Если сборка сообщает ошибки,
не игнорировать их и не заменять рабочую панель: сначала исправить в тестовой копии.
При сборке Docker напрямую npm автоматически не запускается в текущем Dockerfile;
frontend должен быть собран заранее либо через существующий CI workflow.

После сборки проверить маршруты: Users, Hosts, Nodes, Core, WireGuard, XHTTP,
Subscriptions и Login. Отдельно открыть создание/редактирование пользователя,
подтверждение удаления, QR, календарь, меню, редактор JSON, раскрытые аккордеоны.
Проверить обычные/пустые/ошибочные состояния на desktop и мобильном экране.
Если останутся локальные исключения, исправлять их адресно после просмотра,
не добавляя blanket CSS !important ко всем компонентам.

Предлагаемый коммит:

    style(dashboard): unify terminal theme across admin components and settings

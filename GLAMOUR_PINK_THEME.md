# Glamour pink dashboard theme

The dashboard now uses one dark, airy rose design across users, settings, dialogs, navigation and authentication.

## Visual language

- candy-pink primary actions with a soft lilac secondary accent;
- layered plum canvas with fixed pink/lilac atmospheric light blooms;
- translucent glass panels and navigation with restrained blur;
- larger rounded cards, pills and controls;
- Manrope for interface copy and JetBrains Mono only for technical data;
- terminal logs and JSON remain dark and high-contrast for readability;
- semantic warning, error and success colors remain distinguishable.

The change is theme-driven: no API behavior, sing-box accounting, subscriptions, user forms or routing logic is modified.

# Срочное исправление регрессии Hysteria2

## Симптом
После изменения настроек Hosts/core и обновления подписки Hysteria2 может
перестать подключаться. Редактирование пользовательского Salamander-пароля
временно помогает.

## Причина
Рендеры подписок кэшируются. Ключ пользователя включает edit_at, поэтому любое
редактирование пользователя случайно создаёт новый ключ. Изменения Hosts/core
обновляли xray.hosts, но не очищали общий кэш. Клиент мог получить старый
Salamander-пароль и старый ETag. Именно поэтому изменение поля пользователя
выглядело как лечение.

## Исправление
После успешного xray.hosts.update() очищается кэш подписок в пяти путях:
- PUT /api/hosts;
- PUT /api/core/config;
- сохранение XHTTP inbound;
- сохранение WireGuard outbound;
- автоматическое добавление host при создании node.

Инвалидация выполняется после обновления состояния. Следующий запрос строит
подписку заново и получает новый ETag.

Пользовательские obfs/obfs_password восстановлены. Это совместимый overlay:
- пустой режим/пароль наследует host/inbound;
- непустой пользовательский пароль заменяет унаследованный;
- obfs=none явно отключает obfs в экспортируемом профиле;
- пользовательский Salamander должен совпадать с реальным сервером.
Изменение пользователя не меняет server finalmask.

## Проверки и границы
Добавлены 4 регрессионных теста для overlay и наличия cache.invalidate после
каждого refresh. Все локальные тесты пакета проходят, Python compileall и
синтаксический разбор 62 TS/TSX также проходят.

Настоящий Xray, БД, HTTP-кэш клиента и подключение в этой среде не проверялись.
Поэтому сначала применить на тестовой копии. Для быстрой проверки:
1. Получить Hysteria-подписку и сохранить ETag/пароль.
2. Изменить только эффективный Salamander через используемый путь Hosts/core.
3. Повторить запрос со старым If-None-Match: ожидается 200, новый ETag и новый пароль.
4. Обновить подписку в клиенте и проверить подключение.
5. Проверить пользователя с пустым override и пользователя с явным override.

Если серверный пароль не менялся, а соединение всё равно падает, сохранить два
обезличенных результата (до/после: схема, имена query-ключей, ETag; без auth и
пароля) и логи Xray. Не менять пароль ещё раз — это скрывает исходное состояние.
